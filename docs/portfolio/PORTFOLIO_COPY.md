## Final upload checklist

- Keep Trainix first and use `01-trainix-cover.png` as the overall strongest cover.
- Do not use login, signup, loading, empty-state, or isolated workout-detail screens as covers.
- Keep screenshots at 1440×900; avoid aggressive cropping that removes navigation or product context.
- Use no more than three images per project: one promise, two proof screens.
- Keep descriptions outcome-focused; never call a project a practice app, pet project, or learning exercise.
- Add working live-demo and GitHub links only after opening them in an incognito browser and verifying the full page loads.
