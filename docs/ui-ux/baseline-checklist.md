# UI migration baseline checklist

Capture each existing route at 360, 768, 1280, and 1440 px before replacing it.

## Routes

- Login and signup
- Onboarding
- Dashboard
- Workout plan
- Workout runner and completion
- Nutrition plan
- Body Scan upload and results
- Progress
- Profile

## Record for every route

- Primary user task and completion time
- Loading, empty, success, and error behavior
- Keyboard order and visible focus
- Screen-reader names for interactive controls
- Horizontal overflow and text clipping
- Console and network errors
- Largest image and obvious layout shift
- Existing screenshot reference

## Release comparison

The replacement must improve task clarity without losing a currently working action or deep link.
